## 5. Instrucciones para SQL Management Studio

### 5.1 Requisitos Previos

- **SQL Server** instalado (Express, Developer o Standard)
- **SQL Server Management Studio (SSMS)** instalado
- Permisos para crear bases de datos (rol `dbcreator` o `sysadmin`)

### 5.2 Conexión al Servidor

1. Abre **SQL Server Management Studio**
2. En la ventana "Conectar al servidor":
   - **Tipo de servidor:** Motor de base de datos
   - **Nombre del servidor:** `localhost` o `.\SQLEXPRESS` (según tu instalación)
   - **Autenticación:** Autenticación de Windows (recomendado) o Autenticación de SQL Server
3. Haz clic en **Conectar**

### 5.3 Ejecutar los Scripts (Paso a Paso)

#### Opción A: Ejecutar script por script (Recomendado)

1. En el **Explorador de objetos**, haz clic derecho en la carpeta "Bases de datos"
2. Selecciona **Nueva consulta**
3. Abre el archivo `01_fase1_usuarios_personas.sql` (Ctrl+O o Archivo → Abrir)
4. Verifica que el contenido se cargó correctamente
5. Haz clic en **Ejecutar** (F5) o el botón verde en la barra de herramientas
6. Revisa los mensajes en la pestaña "Mensajes" para confirmar que no hay errores
7. **Repite los pasos 2-6 para cada script en orden:**
   - `02_fase2_plantillas.sql`
   - `03_fase3_documentos_parte1.sql`
   - `04_fase4_documentos_parte2.sql`
   - `05_fase5_citas_auditoria.sql`
