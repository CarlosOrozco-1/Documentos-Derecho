## 1. Descripción del Proyecto

Sistema de gestión jurídica que permite:

- **Administrar usuarios y roles** (administradores, abogados, asistentes)
- **Registrar personas** (clientes, compradores, vendedores, notarios)
- **Crear plantillas de documentos legales** con variables dinámicas
- **Generar documentos jurídicos** a partir de plantillas
- **Gestionar el ciclo de vida** de documentos (borrador → aprobado → finalizado → anulado)
- **Trazabilidad completa** mediante historial de estados y auditoría
- **Agenda de citas** con clientes
